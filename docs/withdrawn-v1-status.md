# Отозванный промежуточный запуск

Не использовать как итоговую модель. pandas 2.2.3 неверно декодировал SAS XPT нули как `2**-260`. В complete-case выборку ошибочно включены 152 участника с нулевым fasting weight. Исходный запуск (3 470 участников, test 520) и его метрики сохранены локально для аудита; полный архив исключён из Git. Этот документ сохраняет публичную историю отзыва. Причина исправления — независимая проверка кодбука и декодера, не оптимизация по тестовым метрикам.

Исправленный эксперимент MedPredict-SBP-v2 использует pyreadstat 1.3.1 и те же зафиксированные варианты моделей/seed/критерий выбора. Получено 3 318 участников (2 324/497/497). Внутренний test пересчитан после технической коррекции; первоначальный test уже был просмотрен, поэтому это не новая независимая или внешняя клиническая валидация. Актуальные результаты: [experiment-results.md](experiment-results.md).

Источник: [pandas #50670](https://github.com/pandas-dev/pandas/issues/50670).
