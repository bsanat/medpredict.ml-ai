# Карточка модели MedPredict-SBP-mlp-v2

Обновлено: 21 октября 2026 года. **Статус: университетский исследовательский прототип; `researchOnly=true`, `qualityStatus=experimental`.** Это реально обученная сеть, но клиническая пригодность не установлена.

Главное ограничение: на исправленной внутренней test-части weighted MAE составляет **11,225 мм рт. ст.**; при наблюдаемом SBP ≥150 — **41,366**, все 42 случая этой группы недооценены. Модель нельзя использовать для диагноза, лечения, изменения лекарств или замены измерения давления прибором.

## Назначение и выход

- Задача: экспериментальная оценка среднего текущего систолического давления одного обследования NHANES, а не прогноз будущего давления.
- Выход: число, мм рт. ст.; API-семантика `predictionType=estimated_current_measurement`, `demo=false`. Значение является оценкой, а не фактически измеренным давлением пациента.
- Допустимое применение: демонстрация воспроизводимого ML-процесса и интеграции для диплома, исследовательский анализ ограничений.
- Неподтверждённое применение: клинический скрининг/диагноз, подбор лечения, оценка состояния ребёнка, пациента 80+, беременных или отдельных клинических групп, решение о срочности помощи, использование на населении Казахстана без отдельной проверки.
- Модель не выдаёт валидированные категории риска, вероятности болезни, confidence score или индивидуальный интервал ошибки.

## Данные и история версии

Официальный источник: [CDC NHANES 2017–March 2020](https://wwwn.cdc.gov/nchs/nhanes/continuousnhanes/default.aspx?Cycle=2017-2020); условия [NCHS Data User Agreement](https://www.cdc.gov/nchs/policy/data-user-agreement.html). Когорта 3 318 complete-case участников 18–79 с положительным fasting weight; train 2 324, validation 497, test 497. Target — среднее минимум двух валидных `BPXOSY1/2/3` одного визита. Исходные файлы связываются по `SEQN`, идентификатор не является входом модели. [Аудит и provenance](../reports/data_audit.json), [схема отбора](dataset-selection.md).

v1 отозван из-за неправильного чтения нулей pandas 2.2.3: в него ошибочно вошли 152 участника с нулевым fasting weight. В v2 источник читается проверенным pyreadstat 1.3.1; сетка моделей/seeds/критерий выбора сохранены. [История отзыва v1](withdrawn-v1-status.md), [причина в upstream](https://github.com/pandas-dev/pandas/issues/50670). Полный архив сохранён локально и не публикуется.

Первоначальный некорректный test уже был просмотрен. Результаты v2 — исправленная внутренняя повторная оценка, а не новая внешняя или полностью не просмотренная валидация. Это ограничение не скрывается переименованием версии.

## Входной контракт

ONNX input `features`: `float32[batch,5]`; output `predictedValue`: `float32[batch,1]`. Порядок фиксирован:

| Позиция | Поле | Единица/кодировка | Границы runtime из наблюдённого train |
|---|---|---|---|
| 0 | age | Полных лет | 18–79, целое |
| 1 | sex | `male=0`, `female=1`, соответствует перекодированному `RIAGENDR` | Только эти категории |
| 2 | bmi | кг/м² | 15,4–74,8 |
| 3 | totalCholesterol | Общий холестерин, ммоль/л | 1,97–11,53 |
| 4 | glucose | **Глюкоза плазмы натощак**, ммоль/л | 2,94–25,0 |

Границы взяты из [metadata.json](../artifacts/metadata.json) конкретного артефакта. Это наблюдённая поддержка train, а не медицинская норма, безопасный интервал или гарантия качества для всех комбинаций значений внутри прямоугольника. Нельзя передавать mg/dL вместо mmol/L, глюкозу после еды или произвольно менять код пола/порядок.

Статистики масштабирования входов и target обучены только на train, сохранены с весами и встроены в ONNX; Java не должен применять второе независимое масштабирование. Ни цель, ни отсутствующие входы не импутируются. При неверных/отсутствующих входах, недоступной модели или inference failure приложение должно возвращать ошибку, не демочисло.

## Архитектура и обучение

Стандартная собственная PyTorch MLP `5 → 32 → 16 → 1`: Linear/ReLU, dropout 0,1 при обучении, 737 параметров; линейный выход. AdamW: learning rate 0,001, weight decay 0,05; batch 128; максимум 500 эпох, early stopping patience 40 по validation weighted MAE; сохранён лучший checkpoint. Обучались девять запусков: три конфигурации × seeds 2026/2027/2028. Применяется заранее закреплённый представитель seed 2026 выбранной конфигурации, а не лучший test seed.

Архитектура выбрана по среднему validation weighted MAE трёх seeds; семейство MLP — по validation weighted MAE 10,342 против Ridge 10,732 и бустинга 10,801. Модель не переобучалась на объединении train+validation после выбора. Стандартная MLP не заявляется новой архитектурой; оригинальный вклад — собственные веса, данные/pipeline, проверяемая оценка и интеграция.

## Измеренное качество и ограничения

| Показатель исправленного test, n=497 | MLP |
|---|---:|
| Weighted MAE | 11,225 |
| Weighted RMSE | 15,309 |
| Weighted R² | 0,202 |
| Невзвешенная MAE | 12,396 |
| Невзвешенная RMSE | 16,381 |
| Невзвешенный R² | 0,199 |
| Median absolute error | 9,847 |

Mean weighted MAE — 13,231; Ridge — 11,268; бустинг — 11,698. Отличие MLP–Ridge всего 0,043; устойчивое превосходство MLP не установлено, Ridge лучше по weighted RMSE/R². R² не является classification accuracy.

Условный bootstrap-интервал weighted MAE: 10,141–12,221 после 1 000 masked-PSU resamples внутри strata. Он не является интервалом отдельного результата, полной survey uncertainty или внешней клинической проверкой. Групповые ошибки неоднородны: female 13,061 против male 9,476; возраст 18–39 — 8,412, 60–79 — 13,708; SBP ≥150 — 41,366. Эти описательные срезы не доказывают причинность и не были независимо откалиброваны для клинических групп.

Complete-case fasting selection, неполный контекст лекарств/болезней, один внутренний split, прежний просмотр отозванного test, сложный survey design и изменение распределения ограничивают интерпретацию. Веса не исправляют автоматически отбор по пропускам. Работа на обезличенной выборке США не устанавливает применимость к отдельному пользователю или Казахстану. Полный [отчёт с рисунками](experiment-results.md), [протокол](experiment-design.md).
